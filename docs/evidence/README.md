# Capturas reais do Windows

Este diretório recebe as nove imagens originais fornecidas pelo responsável pelo desafio. A [página de evidências](../EXECUTION_EVIDENCE.md) explica cada uma. **Os PNGs são adicionados pelo script `scripts/import-execution-evidence.ps1` quando o pacote `jungle_evidence_images_only.zip` é importado no clone local**; o ZIP não é armazenado no GitHub.

O script verifica o SHA256 de cada PNG antes de copiá-lo, faz commit sem reescrever o histórico e usa a identidade Git configurada no computador do autor. Os screenshots não incluem o SHA local; não os atribua automaticamente a commits específicos.
