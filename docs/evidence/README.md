# Imagens originais das evidências locais

As nove capturas PNG **já estão versionadas neste diretório**. Consulte [Evidências de execução local](../EXECUTION_EVIDENCE.md): cada imagem está incorporada diretamente abaixo da descrição do respectivo experimento por Markdown `![descrição](evidence/arquivo.png)`.

As imagens foram transferidas em seus bytes originais, sem montagens, capturas simuladas ou alterações de cor/resolução. Cada arquivo teve seu SHA Git validado antes do commit. As capturas são evidências da execução local do responsável, porém não mostram o SHA do checkout local.

O script [import-execution-evidence.ps1](../../scripts/import-execution-evidence.ps1) permanece disponível para conferir a integridade das imagens a partir do ZIP original, mas **não é necessário executá-lo** para visualizar as imagens no GitHub.
